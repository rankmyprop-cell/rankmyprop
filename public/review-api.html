Approved Reviews API

Display Rank My Prop reviews on a prop firm's website. The API only returns reviews that have been approved or published by Rank My Prop moderation.

No API key is required for public approved reviews. Cross-origin browser requests are supported. Please retain visible “Reviews by Rank My Prop” attribution with a link to the source review page.

Endpoints

GET https://www.rankmyprop.in/api/reviews

GET https://www.rankmyprop.in/api/reviews/finotive-funding

The firm-specific path is recommended when embedding reviews on a firm's own website.

Query parameters

firmFirm slug, such as finotive-funding
pagePage number; default 1
limit1–100 reviews; default 20
ratingExact rounded rating from 1–5
minRatingMinimum rating from 1–5
sortnewest, oldest, highest, or lowest

JavaScript example

const response = await fetch(
  "https://www.rankmyprop.in/api/reviews/finotive-funding?limit=6&minRating=4"
);
const data = await response.json();

for (const review of data.reviews) {
  console.log(review.reviewer.name, review.rating, review.text);
}

Response fields

Every response includes firm metadata, aggregate rating statistics, pagination, approved review content, public proof availability, source links, and attribution details. Private user IDs, email addresses, moderation notes, reward data, and rejected or pending reviews are never returned.
